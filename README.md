# Измерение скорости скачивания

Требуется Node.js 22 или новее. Внешние зависимости не нужны.

```bash
node download-speed.mjs 'https://example.com/image.jpg'
```

Укажите прямой HTTP(S)-адрес ресурса. По умолчанию скрипт выполняет 10 последовательных GET-запросов и дочитывает тело каждого ответа перед следующим запросом. При сетевой ошибке, обрыве загрузки или HTTP-статусе вне диапазона 2xx скрипт завершится с кодом 1. Для адреса с перенаправлением укажите конечный URL.

Прогресс запросов выводится в stderr, а итоговые метрики — в stdout.

| Переменная окружения | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `REQUEST_COUNT` | `10` | Число последовательных GET-запросов. |
| `INACTIVITY_TIMEOUT_MS` | `15000` | Таймаут ожидания заголовков или очередной порции тела в миллисекундах. |
| `USER_AGENT` | `download-speed/1.0` | Заголовок HTTP-запроса. Для Wikimedia укажите в нём свой способ связи, например `download-speed/1.0 (you@example.com)`. В Docker передайте значение через `-e USER_AGENT`. |

`REQUEST_COUNT` и `INACTIVITY_TIMEOUT_MS` принимают положительные целые числа.

```bash
REQUEST_COUNT=5 INACTIVITY_TIMEOUT_MS=3000 node download-speed.mjs 'https://example.com/image.jpg'
```

## Запуск в Docker

```bash
docker build -t download-speed .
docker run --rm download-speed 'https://example.com/image.jpg'
docker run --rm -e REQUEST_COUNT=5 -e INACTIVITY_TIMEOUT_MS=3000 download-speed 'https://example.com/image.jpg'
```

Скрипт выводит сообщения на английском. При Ctrl+C (SIGINT) или остановке контейнера через `docker stop` (SIGTERM) скрипт отменяет текущий запрос и завершает работу без итоговых измерений. Коды завершения для SIGINT и SIGTERM — 130 и 143 соответственно.

Если время ожидания заголовков или очередной порции тела превышает таймаут, скрипт отменяет запрос и завершает работу с кодом 1. Получение заголовков или порции тела запускает отсчёт заново.

| Показатель | Единицы и расчёт |
| --- | --- |
| Average request time | Миллисекунды (ms). Среднее время от начала запроса до полного получения тела ответа. |
| Total downloaded | KB, MB или GB. Сумма байтов тел ответов без HTTP-заголовков. |
| Download speed | KB/s, MB/s или GB/s. Общий объём, делённый на суммарное время запросов в секундах. |

Единицы десятичные. 1 KB = 1 000 байт, 1 MB = 1 000 000 байт, 1 GB = 1 000 000 000 байт.
